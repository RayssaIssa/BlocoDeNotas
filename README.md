# 🗒️ Bloco De Notas em py

Segui este <a href="https://data-flair.training/blogs/create-notepad-text-editor-python/">tutorial</a> para fazer um bloco de notas simples em Python usando o Tkinter.

Possui um menu com dois submenus: 
- "Arquivo", com as opções 'Novo', 'Salvar', 'Salvar como' e 'Apagar'.
- "Editar", com as opções 'Cortar', 'Copiar', 'Colar', 'Selecionar', 'Selecionar tudo' e 'Procurar'.
